## 二、本轮修复的问题

| # | 问题 | 修复方案 | 复测结果 |
|---|------|----------|----------|
| 1 | 深链接/刷新 401：直接访问 `/api/v1/users` 等子路由返回 401 JSON | `SecurityProblemHandler.commence()` 识别浏览器文档导航（`Sec-Fetch-Dest: document` 或 `Accept: text/html`），直接回写 classpath 的 `static/index.html`，由前端路由接管 | ✅ 刷新 `/api/v1/users` 正确返回 SPA → 跳登录页 |
| 2 | SSE 错误信息未解析 JSON：对话/问答失败时显示原始 JSON 文本 | `consumeSse` 解析错误体 JSON 提取 `message` 字段 | ✅ 对话错误气泡显示友好消息 |
| 3 | 智能对话失败静默挂起：无错误反馈，会话不保存 | catch 块追加持久化错误气泡进会话列表 | ✅ 错误以"⚠️ 回复失败"气泡呈现 |
